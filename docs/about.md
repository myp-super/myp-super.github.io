# 关于 Deep Reflection

欢迎来到 **Deep Reflection**。

这里不仅仅被限定为科技博客，更像一个持续生长的个人集合：或是冷静的理性剖析，或是细碎的日常片段；或是潜心钻研的课题，或是尚无答案的思索；或是新鲜的前沿分享，或是烟火日常里一张随手记录的照片。

**这里是我记录经历、整理思考，同时也安放感受的一个地方**

## 为什么是“邃思”

“邃”是深入，“思”是思考，也是思绪。

我希望自己既能向问题深处走，也能认真感受生活本身。这里不追求每篇文章都给出结论，有些文字是总结，有些只是记录；有些关于世界，有些只关于当下。

如果这些文字恰好也让你我有所思考、产生共鸣，或者只是陪你停留了一会儿，那就很好。
