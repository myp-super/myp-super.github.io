# 你好，博客

这是这个站点的第一篇文章，用来验证博客的文章列表、标签和分页，也顺手记录以后的写作方式。

## 写文章只需要做什么

在 `docs/posts/` 下新建一个 `.md` 文件，顶部用 `---` 包起来的部分叫做 **frontmatter**，
声明标题、日期和标签，正文用 Markdown 书写，保存后首页会自动出现这篇文章。

```yaml
---
title: 文章标题
description: 一句话摘要
date: 2026-11-16
tags:
  - 标签1
  - 标签2
---
```

## 常用的 Markdown 语法

- **加粗**、*斜体*、`行内代码`
- 列表用 `-` 开头
- 引用用 `>` 开头

> 把复杂的东西讲清楚，是最好的学习方式。
